# V3.11 Slice 11.4 — real cost measurement

## The blocker

V3.10 measured real token consumption but reported

```
cost_per_verified_useful_finding = None
  "no price is recorded for any provider; a cost of unknown is never zero"
```

That refusal was correct — an unpriced provider reported as costless is how a benchmark
picks the wrong one — but it left the provider strategy as a **cost argument with no cost
measurement behind it**.

## The fix, without breaking the design rule

`PriceBook`'s own docstring sets the rule: *"Prices are configuration; they are never
hard-coded here, and a price change must never be a code change."* So no price ships in
the source. Three settings were added, all unset by default:

```python
v3_price_usd_per_million_input_tokens: float | None = None
v3_price_usd_per_million_output_tokens: float | None = None
v3_price_source: str = ""          # provenance, carried beside the estimate
```

`v3_price_source` matters as much as the numbers: an estimate whose provenance is lost is
indistinguishable from a guess. It travels into the run's consumption record.

## The measurement

Real CFR run, real Richemont annual report, real Council:

```
consumption   tool_calls=11  model_calls=9  input=22,224 tok  output=3,525 tok
vendor        azure_openai (gpt-4.1-mini)
useful findings  10 of 10 (0 withdrawn by the red team)

cost_per_company_research_run     = $0.01453
cost_per_verified_useful_finding  = $0.001453
priced from: Azure OpenAI gpt-4.1-mini published list price USD/1M tokens,
             supplied as configuration 2026-09-06 (list price, NOT an invoice)
```

## What these numbers are, and are not

- They are **estimates from a list price supplied as configuration**, labelled
  `cost_basis: estimated_from_configured_prices`. `actual_usd` stays `None` until a
  provider reports a real charge. That distinction is the same one the token counts keep.
- The sample is **one run of one issuer**. It is an acceptance measurement, not a pricing
  study, and a single run's ratio moves with how much evidence the corpus happens to hold.
- The measured cost covers **model tokens only**. Document fetching, extraction and
  PostgreSQL are local and unpriced here.
- A **partly** priced book still names what it could not price: with only an input price
  configured, the estimate is emitted alongside `unpriced_units: ['model_output_tokens']`,
  because an estimate missing its dominant term is worse than no estimate.

> **No cross-provider comparison is claimed.** Only Azure OpenAI ran. No price was invented
> for DeepSeek, Exa, Perplexity, Gemini or Anthropic, and no benchmark against them was
> fabricated for completeness.

## A "useful" finding

One that survived to the Council and was **not withdrawn by the Red Team**. Counting every
statement the model emitted would let a run producing forty retracted claims look
productive.
