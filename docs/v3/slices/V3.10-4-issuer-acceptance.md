# V3.10 Slice 10.4 — real-issuer acceptance

## Objective

Run real issuers through the whole V3 pipeline and look for **correctness failures**, not
for a pretty report.

## The harness

`scripts/v3-issuer-acceptance.py`. Its own scratch database, migrated to head, seeded with
**real public data**, then `run_v3_research` — the same function the front door calls. It
prints what a reviewer needs to find a defect and **exits non-zero if an invariant check
fails**: a chair label outside the five, a forbidden term in the synthesis, a finding with
no support, a segment-scoped finding whose statement says Group, a citation resolving to
nothing.

Seeding is real: `--seed-sec` pulls live SEC XBRL companyfacts; `--seed-corpus-url`
ingests a real issuer document through the repository's own guarded, allowlisted,
DNS-pinned fetcher and the real extractor.

## What the runs found

Six defects, three of them material. Each became a corrective with regression coverage.

| # | Found by | Defect |
|---|---|---|
| 1 | first MRNA run | The pipeline passed a `research_runs` id into `research_tool_calls.research_job_id`, whose FK points at `research_jobs`. **Every tool call failed to persist and took the transaction with it.** Invisible to the unit suite, which runs on sqlite with foreign keys off. |
| 2 | first MRNA run | `lookup_entity` was called with a `company_id`. It resolves an *issuer*, so it takes a ticker — the company row's id is the answer, not the question. Every identity lookup was refused. |
| 3 | first MRNA run | **Biotech's blocking `pipeline_state` needed `get_recent_filings`, which nothing implemented**, so a biotech run could never convene its Council. Corrective: the tool. |
| 4 | MRNA with real SEC data | **Every finding carried `period_key=None`** while citing facts that had one; three said "FY2026 projected" for FY2025 actuals. Corrective: findings inherit period and scope from their evidence. |
| 5 | the harness itself | SEC's `as_of` is the period end for a reported concept and the **filing date** for a derived one, so FY2025 derivations arrived stamped 2026. |
| 6 | CFR run | 170 of 173 chunks from a real 160-page annual report carry **no scope at all**, including the one containing the Specialist Watchmakers figure. Not a defect — a recorded limitation; see below. |

## What ran, and what each proved

### MRNA — Moderna, NASDAQ

Live SEC XBRL: **29 datapoints, CIK 1682852, 10-K filed 2026-02-20**, seeded as 24 real
facts. The live response **mixes periods across concepts** (revenue as of 2022-12-31 beside
net income as of 2025-12-31), and each fact keeps its own.

Best run, two passes:

```
council   convened=True  findings=3  gaps=10
red team  challenges=1  resolved=1  withdrawn=0  unknown_targets=0
chair     label=reject_for_now  setup=cautious  fallback=False
          key_points=3  discarded_citations=1
delta     unchanged_thesis=True  new_evidence=4  resolved_questions=1  new_gaps=1
findings  [group|2025] all three
consumption  tool_calls=15  model_calls=8  in=15,341 tok  out=1,689 tok
```

**The period guard fired on real data:**

```
gap [conflicting_sources] A statement was discarded because the evidence it cites
                          does not agree on periods ['2025', '2026'].
```

That is the crown-jewel invariant reaching model output for the first time.

### CFR — Richemont, SIX

Slice 4.10's **bounded traversal ran live** against `richemont.com`: 3 pages, robots.txt
consulted, frontier emptied, one page correctly flagged **partially inaccessible** (JS-
rendered). It found the real FY26 annual report, the interim report, results presentations
and **transcripts**.

The real **8.8 MB, 160-page** FY26 annual report was then fetched and ingested: 40 of 160
pages under the live profile, 173 chunks, all indexed. Five findings.

The Council **refused** — `blocking_question_open`: luxury's `segment_discipline` requires
`get_segment_facts`, and no segment facts were seeded. Correct behaviour.

### ASML — AMS

The real annual-report page (236 KB) ingested to 18 chunks. Council refused on
`cycle_position`: the model correctly reported "no information found on bookings, backlog,
book-to-bill ratio, or lead times" — the landing page does not contain them.

### The convened path

No playbook applies ⇒ the Director's baseline has no blocking question ⇒ the Council can
convene. This is a supported, labelled path, and it is what exercised the Red Team and
Chair on real data. One run is worth recording in full: the Red Team challenged the single
real finding, the responder **conceded with evidence**, and the finding was **withdrawn** —
after which the Council was re-assembled, had nothing left, and the Chair honestly said
`insufficient_data`.

## The Group/segment regression

> A Specialist Watchmakers figure must never be promoted to Group scope.

The real corpus contains the trap verbatim:

> *"The Group's Specialist Watchmakers reported sales of € 3.1 billion…"*

It contains the word **Group**, it is about a **segment**, and the figure is the segment's.
Its chunk carries **`scope_key = NULL`**, so a finding built on it inherits **no** scope —
unknown, which is not Group. **Scope integrity here holds by absence rather than by correct
labelling**, and that is recorded rather than glossed: a reader must be able to tell
"labelled segment" from "declined to label".

Five regression tests use the real sentence, including that a model writing *"the Group's
sales were €3.1 billion"* over segment-scoped evidence still gets **segment** scope,
because scope is inherited and never read out of prose.
