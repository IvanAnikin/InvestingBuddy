# V3.4 Slice 4.1 — Provider interfaces, governance and routing

**Branch:** `feature/v3-4-1-provider-interfaces` · **Merge target:** `develop/v3` only
**Migration:** no · **Infrastructure:** no · **Provider dependency:** none — this slice ships **no live adapter**
**Feature flag:** `V3_PROVIDER_RUNTIME_ENABLED` (default **off**)

## Objective

The four interfaces every other V3.4 slice is an adapter behind — `ModelProvider`,
`SearchProvider`, `ResearchProvider`, `BrowserProvider` — plus the canonical result
contract, the per-provider data-governance matrix, the model routing slots, and a fake
for each.

## Why this is the only V3.4 work completable now

Every other slice in the phase is an adapter, and three are blocked on **user-owned**
decisions: [#3](../OPEN_DECISIONS.md#3-exa-vs-perplexity-search) (Exa vs Perplexity,
spend), [#4](../OPEN_DECISIONS.md#4-deepseek-data-governance-policy) (DeepSeek
governance), [#8](../OPEN_DECISIONS.md#8-transcript-provider) (transcript vendor). The
interfaces and the fakes are what can be finished without any of them — and the fakes are
not a lesser deliverable: what these slices must prove is what the platform does *with* a
provider's output, and a live client would make every one of those proofs depend on a
vendor's uptime and spend money to demonstrate a refusal.

## The one rule the contracts encode

> External research agents discover and investigate. InvestingBuddy verifies, persists,
> calculates, reconciles, remembers and determines what may enter the canonical
> investment-research record.

So a provider's output is a **`ResearchLead`**, never evidence, and the type makes that
hard to forget: every claimed field is *named* `claimed_*`. A field called `value` would
be read as a fact by the next person to touch it; `claimed_value` cannot be.

**Unverifiable is not the same as rejected.** A lead citing no URL cannot be checked *by
construction* — it is not wrong, and recording the two alike would blame a provider for
failing a check it was never eligible for. `unverifiable_lead_count` is therefore a
quality signal about the provider available *before* any verification has run: a provider
whose leads mostly cite nothing cannot contribute evidence however good its prose is.

The eight rejection reasons are exactly those in
[DATA_AND_EVIDENCE_ARCHITECTURE.md §4.2](../DATA_AND_EVIDENCE_ARCHITECTURE.md#42-researchlead),
closed, because `verification_survival_rate` per provider is the whole reason rejections
are kept.

A `SourceCandidate` has no `text` field. A URL a search index returned is a *claim that a
page exists*; the platform's own guarded fetcher is what turns it into bytes with a hash,
and only those bytes can be cited. Its provider-supplied snippet is labelled untrusted.

## Governance is a matrix, and it denies by default

[#11](../OPEN_DECISIONS.md#11-private-data-external-model-policy) is explicit that **both**
dimensions are required: "external models are allowed" and "*this* provider, in this
jurisdiction, under these retention terms, is allowed" are different questions, and a
single per-run flag is exactly the coarse control that leaks one document.

Four properties make it enforceable:

- **An unrecorded provider may receive nothing.** Not a permissive default — a provider
  nobody has recorded a policy for is one nobody has *evaluated*.
- **A private class cannot be granted to an external provider at all**, and granting one
  to an *internal* provider requires an authority string that names #11. "It runs in our
  tenancy" is a statement about where it runs, not an answer to whether private material
  may be sent to it.
- **A grant with no recorded authority is refused.** A grant nobody can audit is a grant
  nobody reviewed.
- **A payload can be split.** `filter_permitted` returns the permitted and the refused
  halves, so a run can send the public part of an evidence pack to a cheap provider,
  keep the rest local, and **say what it withheld** instead of silently sending less.

DeepSeek is the worked example and is public-only while #4 is open. Worth noting what the
strategy document establishes alongside it: the price case is weaker than assumed — at
this platform's call shape DeepSeek is 1.4× cheaper off-peak and **30% more expensive at
peak**, and runs are user-triggered so off-peak cannot be chosen. Cheap does not override
governance, and here it does not even buy much.

## Domain logic names a slot, never a model

Eight slots. Every one defaults to **empty**, because
[#5](../OPEN_DECISIONS.md#5-openai-model-routing) is open and its own recommendation notes
that absolute cost is small (~$0.19/report for a cheap-analyst/strong-Chair split) — so
the decision is about **rate-limit headroom**, not the bill. Guessing a default would
answer a question asked of somebody else.

An unresolvable slot **degrades and names which of three reasons applied**:
`slot_not_configured`, `provider_not_registered` (usually a missing credential) or
`governance_refused`. Collapsing them into one `None` would hide "nobody configured this"
behind "governance refused this", which have different owners.

A shared vendor between Chair and Red Team is **reported, not forbidden** — one vendor is
a legitimate configuration while a second is being evaluated, and what matters is that it
is visible the diversity argument is not currently being had.

## What the review pass found

1. **`resolve(slot)` defaulted `access_class` to `None`, which skipped the governance
   check entirely.** A caller that forgot the argument got an unchecked provider — a
   fail-open in the module whose whole purpose is the check. It is now **required**, and
   the no-content case has to be spelled out as `NO_CONTENT` rather than defaulted into.
2. **A private grant to an *internal* provider bypassed #11.** The check only applied to
   external ones, so `is_external=False` was a way round it. Any private grant now
   requires an authority naming the decision.
3. A leftover nonsense assertion in a test, removed.

## Acceptance criteria

1. **A provider claim is a lead, and an unverifiable lead is counted as such** — distinct
   from rejected, with a closed rejection vocabulary.
2. **Governance denies by default**, a private class cannot be granted to an external
   provider by editing an allowlist, and the check happens *during* slot resolution.
3. **No live adapter and no vendor SDK exists in the package** — asserted by a test that
   enumerates the module list, so #3/#4/#6/#7 must be taken deliberately.
