## Operational findings

- **Migrations do not run on deploy.** After #405 deployed, `/market-discovery/runs` returned 500 until migrations 062–064 were applied by hand over SSH. See DEPLOYMENT.md, "Running migrations on staging". A migration step in the deploy workflow is an owner decision.
- **CI timing test.** `test_every_pattern_is_linear` measured garbage-collection pauses. It is now GC-proof.
- **`main` has no required status checks.** `gh pr merge --auto` therefore merges immediately.
