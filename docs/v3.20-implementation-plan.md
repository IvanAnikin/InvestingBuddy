- **Branching**: one PR-sized slice per `feature/v3-20-<phase>-<slice>-<name>` branch, PR into `main`, as the research-integrity closure PRs (#319–#337) did. Nothing is deployed until the owner approves. *Note:* the "Branch Discipline" section of `CLAUDE.md` still names `develop/v3` as the V3 target although V3 was activated on `main` on 2026-09-08. Reconcile that section in slice 0.1.
- **Deployment**: `main` @ `e8d57c2`+ is not yet deployed. Azure is suspended until about 11-16, and the closure deploy plus migration 046 goes first. V3.20 migrations start at **047**.
- **Every slice** ships with: tests (unit + one real-shape fixture), a feature flag defaulting **off**, docs (ADR if a rule changes, DATABASE.md/API.md if touched), and a security scan. Live acceptance happens after deploy, on real issuers (spec §5).
- **ADRs** start at **ADR-097**.
- **Order logic**: the owner's six asks come first. They are also what laddering, obscurity and demand triangulation depend on, so building them first is not a detour.

Done-criterion for the sprint: on a real < USD 2bn grid-equipment issuer, one report shows a verified size, parent & group, customers, suppliers, ETF holders and an earnings track record, each cited or explicitly `not_disclosed`.

## 4. Risks

| Risk | Mitigation |
|---|---|
| Customer/supplier names are mostly anonymous or undisclosed for small caps | Anonymous concentration is still a fact; the "not disclosed" state is first-class; the inverse edge (the customer names the supplier) is often the only source, so 2.5 reads customers' documents too. |
| Wrong-subject attribution (a peer's customer reported as ours) | Mandatory ADR-083 firewall + verbatim check; a dedicated regression set in 2.5. |
| N-PORT volume on B1 / Azure PG | Aggregate-only storage; ingest as an offline job; raw ZIP in blob. |
| Alpha Vantage limits/terms/coverage (US-centric, 25/day, private use) | Shortlist-only use, cache, `source_unavailable` state, guidance fallback; FMP only by owner decision. |
| Consensus, verdicts and fair value re-open the advice risk (D3/D4/D5/D9) | Field-scoped allow-lists (0.3); deterministic verdict and valuation; disclaimer on every rendering; **private use only**; a public launch requires a regulatory review, not a flag flip. |
| Fair value from thin evidence = confident hallucination | `insufficient_evidence` fail-closed; ranges, not points; every assumption named; thin evidence caps the verdict at WATCHLIST. |
| Issuer ETF file layouts change without notice | Schema-drift check fails closed; one adapter per sponsor; N-PORT remains the backbone. |
| Asia scope (Phase 11) is large | It is its own phase after the core; each connector is independent. |
| Scope creep from the vision (Phases 5–10 are large) | Phases ship independently behind flags; every phase is useful alone. |
