# V3.20 Phase 11 — Asian primary disclosure and grid plans (spec §3.13; D6)

Status: slice **11.1 implemented 2026-11-17** for the Taiwan Stock Exchange (V3 line, not
deployed). The other Asian sources were assessed and are recorded below. Most need an
owner decision: an API key the owner creates, or a terms question.

## 11.1 Exchange directories

Official exchange directories are discovery's first-ranked listing source
(`app/services/discovery/directories.py`, V3.19.10). A lead's listing on a venue is
verified when that exchange's own list carries it. The size constraint uses the
exchange's own market capitalisation when the exchange publishes one.

### Taiwan Stock Exchange — built

| | |
|---|---|
| Files | `https://openapi.twse.com.tw/v1/opendata/t187ap03_L` (listed company basic information) and `.../v1/exchangeReport/STOCK_DAY_ALL` (daily trading, closing price) |
| Licence | data.gov.tw, Open Government Data License v1.0: any purpose, royalty-free, **attribution required**. The OpenAPI is TWSE's agreed machine-access method. |
| Flag | `V3_DIRECTORY_TWSE_ENABLED` (default **on**) |
| Venue | `TW` (XTAI, TWD) |
| Name used | `英文簡稱` (English short name, e.g. "TSMC"); else the Chinese short name |
| Market cap | `已發行普通股數或TDR原股發行股數` (issued common shares) × `ClosingPrice` of that day. The basis names both figures, the price date and the attribution. |

Rules:
- A ticker match needs the name to agree. TWSE's English names are often acronyms, so an
  acronym now agrees when the ticker already matched, three to six letters, spelling the
  initials of the lead's full name in order with every word used, except legal words at
  the end ("TSMC" = "Taiwan Semiconductor Manufacturing Company Limited"). A real code
  paired with another company is still refused.
- No closing price that day (no trade) means no market cap, never a zero.
- A TDR (code `91xx`) gets no market cap: its file states the underlying shares, not the
  receipts the price is quoted for.
- TWSE's open data carries no ISIN. None is derived.
- ROC calendar dates (`1151116`) are read as ISO (`2026-11-16`).
- Each directory now has an optional flag. A directory whose flag is off is "no
  directory" (no request, no verdict), not "directory unavailable".
- Venue names: "Taiwan Stock Exchange", "TWSE", "KOSPI", "KOSDAQ", "Korea Exchange",
  "XTKS" and the Indian exchanges now resolve. Ticker suffixes `.TW`, `.KS`, `.KQ`,
  `.NS`, `.BO` are stripped.
