### Run 2 — job `036d90a2-5755-4d29-af79-8199f1719a1d`, report `347512a1-4c02-4218-a5bb-1dfa0fc71caa`, API `d5cb416` (2026-09-22)

`OBSERVED IN PRODUCTION`: 54 findings, `is_complete_analysis: true`, 339 chunks indexed
before planning, 3 rounds / 12 tasks / 92 tool calls / 15 external searches, 8
restatements referenced rather than repeated.

Read critically, it still failed four ways:

1. The corpus held the 2026-Q2 10-Q and the 10-K's **exhibit index**, not the 10-K — so
   the business, segment, reserves and production questions had nothing to read, and
   several findings were exhibit-list trivia.
2. Profitability, revenue trajectory and valuation were re-asked from run 1's gaps
   **without** the statements tool: the prior-gap restoration copied the definition field
   by field and missed `optional_tools`.
3. Statements about what the evidence lacked ("No cited evidence names AI hardware…")
   were recorded as **findings**; they graded thesis dimensions `evidenced` and led the
   executive synthesis. One inferred "exposure reads as weak" from absence — the D3
   defect in a new place.
4. All 16 editor sentences were rejected `cites_no_finding`: the model grouped its labels
   as `[F1, F2]`.

Fixes (PR #225): the latest annual and quarterly reports are secured into the corpus
through the V3.16 bridge **before** planning; the prior-gap restoration takes the whole
definition; statements about the evidence become platform gaps (and an absence-derived
"weak" conclusion with them), with the writers told so and the thesis question saying
absence in what was read is not a weak link; grouped citations are citations; the
deterministic synthesis leads with each section's most informative finding.
