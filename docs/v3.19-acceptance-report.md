## 2. OBSERVED IN PRODUCTION

Environment: `ib-stg` (the single private-use production). Deployed SHAs as each
observation was made are stated beside it. Every figure below was read from the
production API response, not from logs or memory.

### 2.1 Vendor finding that shaped the phase (2026-09-26)

The research provider's builtin web search stopped issuing searches on every model and
prompt (the tool is accepted and never called). With thinking on, a 4,000-token
company-list request spent every token reasoning and returned an empty message. The
first production luxury run (`30500bf8`) therefore got 0 external leads. V3.19.10
replaced retrieval with **model recall + official exchange directories** (no new
service, no new cost): a recalled name is worth nothing until the exchange's own list
confirms it.

## 4. KNOWN LIMITATIONS

- **Web search outage (vendor, 2026-09-26).** Discovery runs on model recall verified by
  official directories. Recall favours companies a model knows; a genuinely obscure
  issuer may never be proposed.
- **Venues without a readable directory or market cap.** Frankfurt/Xetra (leads cannot be
  verified at all), Copenhagen (no directory), SIX and TSX/TSXV (listing yes, market cap
  no), US (Nasdaq refuses non-browser clients; the platform does not spoof a user agent —
  the SEC public float is used only as a lower bound).
- **Growth coverage.** Verified growth comes only from (a) a held company's own validated
  group-scope revenue pair in one primary document or (b) a verified screening passage.
  For most candidates growth is `unknown`, so a "growing" request leaves them
  `eligible_unverified` — honest, but thin.
- **Non-US primary documents.** An LSE/ASX small cap has no filing connector: its deep
  research has no evidence and a blocking playbook question refuses the Council.
- **Industry evidence** is a clause-level keyword match on the issuer's own pages; it can
  land on a headline rather than a self-description.
- **A bare "critical materials" query** yields no industry classification (nothing
  verified says which industry the company is in).
- **Size-verdict guard** misses word-order variants ("outside the size range requested").
